# CalShow

Show your Google Calendar events on your WordPress site: list, month, week and day views, an accessible event window and "Add to calendar" links. Read-only: CalShow never changes your calendars.

This repository publishes the release packages of CalShow. WordPress updates the plugin from here, with no token or setting.

## Install

1. Download `calshow-X.Y.Z.zip` from the **[latest release](https://github.com/edjavi/plugin-calshow/releases/latest)** (under **Assets**). Do not use **Source code (zip)**: that is not the plugin.
2. In WordPress, go to **Plugins → Add New → Upload Plugin**, choose the ZIP and activate it.
3. New versions then show up in **Dashboard → Updates**, like any other plugin.

## Requirements

- WordPress 6.6 or later
- PHP 7.4 or later
